## Notas

1. Limites
   - Limitar el número de proyectos a crear por usuario (máximo 3).
   - Limitar el número de usuarios por proyecto (máximo 10).
   - Limitar el número de tareas por usuario (máximo 50).
   - Limitar el número de procesos por proyecto (máximo 10).
   - Limitar el número de subprocesos por proceso (máximo 4).
